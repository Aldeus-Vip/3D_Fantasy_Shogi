# 基本構想(確定事項)

## 1. ゲーム概要
- 将棋のルールで対戦する 3D ゲーム
- 駒はファンタジーキャラクターの 3D モデル

## 2. モデルセット
- 「Dragon」「Undead(骸骨)」「Demon(悪魔)」などの **モデルセット** を選択式で使う
- 1つのセット = 将棋の駒すべて(成駒を含む)を揃えた一式
- セット候補は随時追加する → [MODEL_SETS.md](MODEL_SETS.md)

## 3. 3Dモデル制作フロー
1. Claude が Firefly 用キャプション(テキストプロンプト)を作成
2. Firefly で画像を生成
3. その画像を Meshy の Image-to-3D に入力して 3D モデル化
4. 生成モデルをゲームに取り込む

## 4. 演出(Animation / Effect)
以下の3場面で必ず演出を入れる。

| 場面 | 演出の例 |
|---|---|
| 移動 | 歩く・飛ぶ・跳ねる(駒の種類ごと) |
| 駒を取る | 攻撃モーション → 相手駒の消滅エフェクト |
| 駒を打つ(配置) | 召喚エフェクト(魔法陣・光柱など) |

追加候補: 成り(進化エフェクト)、王手、詰み。
