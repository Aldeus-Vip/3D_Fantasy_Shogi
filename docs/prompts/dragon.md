# Dragon セット — Firefly / Meshy 用プロンプト

## 使い方
1. 下の「共通スタイル」を各プロンプトの末尾に付けて Firefly で画像生成
2. 生成画像を Meshy の **Image to 3D** に入力
3. 出力形式は **GLB** を推奨

## Meshy 向け画像のコツ
- 被写体は **1体のみ**、全身が画面内に収まる
- **無地の背景**(白またはグレー)
- やや斜め前(3/4ビュー)から
- 台座・地面・影・文字は入れない
- 人型キャラは **A ポーズ**(腕を少し下げて広げる)→ 自動リグが効きやすい

## 共通スタイル(各プロンプトの末尾に付ける)
```
, single character, full body, 3/4 front view, standing pose, plain white background, no ground, no shadow, no text, stylized fantasy game figure, chibi-like proportions, clean hand-painted texture, high detail, centered composition
```
